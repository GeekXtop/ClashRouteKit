# ClashRouteKit 控制台重设计 · 计划 1/4：core 渲染基础

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 扩展 `@clash-route-kit/core` 的数据模型与 INI 渲染器，支持重设计所需的「规则分段、可配置模板开关（含 clash_rule_base）、项目级全局移除清单」，且对策略组/REJECT/多订阅筛选零改动（已验证现有模型足够）。

**Architecture:** 所有 schema 与渲染逻辑留在 `packages/core`（纯函数，无文件 IO）。`renderIni` 增加可选第二参数承载模板开关，并在规则之间按 `section` 输出 `;` 注释分隔。新增字段对 YAML parse/serialize 透明（`configDocument` 已放行未知字段）。本计划**不动** cli/web。

**Tech Stack:** TypeScript（`module: NodeNext`，相对 import 必须带 `.js`）、vitest、yaml。

## 本系列的拆分（scope check 结论）

设计横跨三个子系统，拆成 4 份按依赖排序、各自独立可测的计划：

1. **计划 1（本文）· core 渲染基础** — `renderIni` 模板开关 / clash_rule_base / 分段注释 + schema 字段。
2. **计划 2 · core 解析能力** — `parseDomainListEntry`（geosite 目录枚举：include 树 + 域名计数）、`parseIniToConfig`（导入 INI 反解析）。纯函数。
3. **计划 3 · CLI** — `generate` 应用全局移除清单 + 透传模板开关；新增 `import` 命令；`preview` 分段感知。
4. **计划 4+ · Web 控制台（5 标签 IA）** — 落地「规则目录 / 规则源 / 策略组 / 路由 / 发布」。该分支已有进行中的组件重构（`RuleSet*`/`RuleProvider*`/`CustomProxyGroup*`/`RuleFile*`），动笔前需先通读现有 web 代码再细化。

**#9 决定（vendorRepos/ruleProviders 是否拆出 routes.yaml）：不拆。** 三处消费方（cli `readConfig`、web `?raw` import、测试）都按单文件解析，且 web 本地优先要读写单一文件最简单；UI 已按标签分离关注点，物理拆分只增不减复杂度。`config/routes.yaml` 维持唯一配置源。

```ts
export function renderIni(config: RouteKitConfig, options: RenderIniOptions = {}): string {
  const ruleLines = config.ruleSets.flatMap((ruleSet) =>
    renderRuleSet(ruleSet, config.publishBaseUrl),
  );

  const groupLines = config.customProxyGroups.map(renderCustomProxyGroup);

  const tail: string[] = [];
  if (options.clashRuleBase) {
    tail.push(`clash_rule_base=${options.clashRuleBase}`);
  }
  tail.push(`enable_rule_generator=${options.enableRuleGenerator ?? true}`);
  tail.push(`overwrite_original_rules=${options.overwriteOriginalRules ?? true}`);

  return [
    "; Generated by ClashRouteKit",
    "[custom]",
    "",
    ...ruleLines,
    "",
    ...groupLines,
    "",
    ...tail,
    "",
  ].join("\n");
}
```

```ts
  const ruleLines: string[] = [];
  let lastSection: string | undefined;
  for (const ruleSet of config.ruleSets) {
    if (ruleSet.enabled === false) continue;
    if (ruleSet.section && ruleSet.section !== lastSection) {
      ruleLines.push(`; ${ruleSet.section}`);
      lastSection = ruleSet.section;
    }
    ruleLines.push(...renderRuleSet(ruleSet, config.publishBaseUrl));
```
