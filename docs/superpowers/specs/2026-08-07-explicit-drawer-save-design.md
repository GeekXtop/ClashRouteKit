# 抽屉显式保存与策略字段简化设计

日期：2026-08-07
状态：已在对话中确认

## 1. 背景

路由页当前直接把策略组、RuleSet 和项目默认值抽屉中的每次字段变化写入全局项目草稿。`App` 又会在草稿变脏 600 毫秒后自动把完整配置写回 `config/routes.yaml`。

开发环境同时通过 Vite `?raw` 导入该 YAML。写盘触发 Vite 文件监听和整页重载，React 选择状态被重新初始化，因此在策略组下拉框中选择任意值后会退出抽屉并返回默认首页。

当前编辑器还存在三处语义问题：

- 项目级 `GEOIP 默认 no-resolve` 把程序兜底值暴露成第三个选项，与显式开启在当前项目中的行为重复。
- `nodeFilters` 是正则文本数组，却使用标签下拉框编辑。
- 单组 `timeout` 和 `tolerance` 把 `null` 暴露为单独的“明确留空”模式，增加了不必要的状态。

## 2. 目标

1. 策略组、RuleSet、项目默认值三个抽屉改为显式“保存 / 取消”。
2. 抽屉编辑期间不修改全局项目草稿，也不触发自动写盘。
3. 保留规则开关、排序、增删、导入和其他现有操作的自动保存行为。
4. 修复 `config/routes.yaml` 写盘触发 Vite 整页重载的问题。
5. 将节点过滤正则改为多行文本编辑。
6. 删除“明确留空”选项，以“自定义且输入为空”表示 `null`。
7. 项目级 GEOIP 默认值仅提供开启和关闭，并在保存时写入明确布尔值。

## 3. 非目标

- 不把整个项目改成统一的全局手动保存。
- 不改变列表文件编辑器、规则源配方编辑器或发布页现有保存方式。
- 不改变 SubConverter INI 中 `timeout`、`tolerance` 和 `no-resolve` 的渲染规范。
- 不删除 Core 对缺失项目默认值的兜底解析；测试或最小配置仍可省略 `defaults`。
- 不修改策略组或 RuleSet 的全局排序语义。

## 4. 保存模型

三个抽屉采用本地事务式编辑：

```text
打开抽屉
  → 深拷贝当前实体到本地编辑草稿
  → 字段变化只更新本地草稿
  → 保存：校验完整草稿并一次提交
  → 取消/关闭：丢弃本地草稿
```

抽屉在以下情况重新初始化本地草稿：

- 从关闭变为打开；
- 打开时切换到另一个策略组或 RuleSet；
- 项目默认值抽屉重新打开。

父页面不持有逐字段临时状态，只接收抽屉保存后的完整结果。这样临时编辑状态与页面导航状态解耦，并避免多个页面重复实现暂存逻辑。

### 4.1 策略组保存

`GroupDrawer` 保存完整 `CustomProxyGroup`。父层使用单次原子 mutation 完成：

- 名称修改；
- 类型、成员、节点过滤正则和健康检查覆盖值更新；
- 策略组重命名后同步更新父策略组 `options` 和 RuleSet `policy` 引用；
- 保持策略组在数组中的原始位置。

名称必须非空且不能与其他策略组重复。校验失败时抽屉保持打开，不修改项目草稿。

### 4.2 RuleSet 保存

`RuleDrawer` 保存完整 `RuleSet`，包括 ID、来源、策略、section 和启用状态。保存时保持该 RuleSet 在数组中的原始位置；ID 必须非空且不能与其他 RuleSet 重复。

### 4.3 项目默认值保存

`ProjectDefaultsDrawer` 编辑本地 `RouteKitDefaults` 副本，点击保存后一次替换项目默认值。

项目级 `geoipNoResolve` 的 UI 仅有开启和关闭。输入配置缺少该字段时，本地编辑草稿将其初始化为 `true`；点击保存后始终写入明确的 `true` 或 `false`。

单条 GEOIP RuleSet 仍保留“继承项目默认值 / 开启 / 关闭”，因为单项继承和单项覆盖是三个不同语义。

### 4.4 删除操作

抽屉内删除按钮仍采用二次确认并立即修改项目草稿，随后走现有自动保存。未保存的本地字段修改不会参与删除。

## 5. 节点过滤正则

`nodeFilters` 改为多行文本框：

```text
每一行 <-> nodeFilters 数组中的一项
```

规则如下：

- 打开时按换行符连接现有数组。
- 保存时兼容 CRLF 和 LF 分行。
- 全空白行被忽略。
- 非空行保持输入顺序。
- 不把多行内容解析为下拉选项，也不对正则语法做改写。

## 6. 继承与空值语义

`InheritedSettingField` 的模式由三种缩减为两种：

```ts
type InheritedSettingMode = "inherit" | "custom";
```

映射规则：

- `undefined`：继承项目默认值。
- 数值或字符串：自定义覆盖。
- `null`：仍属于自定义模式，但输入框为空。

只有 schema 允许 `null` 的单组 `timeout` 和 `tolerance` 可以把自定义空输入保存为 `null`。重新打开时，这两个字段显示“自定义”及空输入框。

URL、interval、Rule Provider interval 等不允许 `null` 的字段选择自定义后必须填写合法值；为空时显示字段错误并阻止保存。切换到继承会写入 `undefined`。

## 7. Vite 文件监听

保留 `App` 现有 600 毫秒项目自动保存机制，但在 Vite 开发服务器中忽略实际配置文件路径：

```text
CLASH_ROUTE_KIT_ROOT + CLASH_ROUTE_KIT_CONFIG
  → 解析为绝对配置文件路径
  → 添加到 server.watch.ignored
```

默认路径为仓库内 `config/routes.yaml`。环境变量指定其他配置文件时，忽略项必须跟随实际路径。

该改动只阻止 Vite 将应用自己的配置写盘识别为源码变化；API 仍正常写入文件，其他源码和配置目录继续参与开发监听。

## 8. 组件接口

抽屉接口从逐字段事件改为完整保存事件：

```ts
GroupDrawer({ group, onSave, onCancel, onDelete, ... })
RuleDrawer({ ruleSet, onSave, onCancel, onDelete, ... })
ProjectDefaultsDrawer({ defaults, onSave, onCancel, ... })
```

`onSave` 仅在完整校验通过后调用一次。遮罩、关闭按钮和“取消”共享同一取消逻辑。

需要新增或调整纯函数，以便独立测试：

- 策略组完整替换及重命名引用更新。
- RuleSet 完整替换。
- `nodeFilters` 文本与数组转换。
- 项目默认值本地初始化和压缩，确保 `geoipNoResolve` 明确写入。

## 9. 校验与错误处理

保存策略组时校验：

- 名称非空且唯一；
- 自定义 URL 是 HTTP/HTTPS URL；
- interval、timeout 为正整数；
- tolerance 为非负整数；
- 允许 timeout/tolerance 为 `null`。

保存 RuleSet 时校验：

- ID 非空且唯一；
- 来源类型要求的值、文件和 behavior 完整；
- 自定义 Rule Provider interval 为正整数。

保存项目默认值时沿用 Core 默认值校验，并确保 `geoipNoResolve` 为布尔值。任何校验错误都显示在当前抽屉内，不提交全局草稿，也不关闭抽屉。

自动写盘失败继续使用现有全局错误通知和项目状态提示。

## 10. 测试与验收

### 10.1 纯函数和 mutation

- 策略组完整保存一次更新全部字段并保持数组位置。
- 策略组重命名同步更新所有引用。
- RuleSet 完整保存保持数组位置并拒绝重复 ID。
- 节点过滤正则多行文本按顺序转换，忽略空行。
- 项目默认值缺少 `geoipNoResolve` 时初始化为 `true`，保存后明确写入。

### 10.2 抽屉组件

- 修改任意字段不会立即调用保存回调。
- 等待超过 600 毫秒仍不会提交抽屉内容。
- 点击保存只调用一次，并传出完整对象。
- 点击取消、遮罩或关闭按钮不调用保存回调。
- 关闭后重新打开恢复最新已保存值，不保留被取消的临时值。
- `nodeFilters` 使用多行文本框而非 Select。
- `timeout/tolerance` 不再出现“明确留空”，自定义空输入输出 `null`。
- 项目 GEOIP 默认值只出现开启和关闭。
- 单条 GEOIP 规则仍显示继承、开启和关闭。

### 10.3 页面和浏览器回归

- 策略组、RuleSet、项目默认值三个入口都使用保存/取消模型。
- 规则开关、排序、增删、导入等现有操作继续自动保存。
- 在策略组抽屉修改下拉框并等待，不写入 `config/routes.yaml`。
- 点击保存后配置写盘，但当前页面不重载、不跳回规则库首页。
- `pnpm test`、`pnpm typecheck` 和 `pnpm build` 全部通过。

## 11. 已确认决策

- 仅三个抽屉改为显式保存；不引入全局手动保存。
- 使用抽屉内部本地草稿，不使用页面暂存或全局修改后回滚。
- 节点过滤正则采用多行文本框，每行一项。
- 删除“明确留空”选项；nullable 字段用自定义空输入表达 `null`。
- 项目 GEOIP 默认值只有开启/关闭，缺失时按 `true` 初始化并在保存时明确写入。
- 单条 GEOIP 规则保留继承/开启/关闭。
- 保留其他操作的自动保存，并通过 Vite 忽略实际配置文件修复整页重载。
